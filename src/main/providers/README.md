# Provider artwork

Each provider's `logo.png` is its editable rectangular wordmark. It appears in the usage box, Settings, and avatar placeholders in both windows. The built-in images are 95 × 47 pixels; the interface scales them to fit each location. A provider without a logo uses its catalog's fallback mark instead.

Edit the PNGs in an image editor, then rebuild or restart the development app to pick up the changes. The files are bundled into the application, so changing an installed application's source files is not a user-facing customization setting.
